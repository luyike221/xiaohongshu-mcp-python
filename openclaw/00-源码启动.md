下面是对 `openclaw/00-源码启动.md:1-29` 的结构化整理（保持原有步骤与命令不变，只把内容排版成更清晰的文档结构）：

## 1. 安装依赖
```bash
cd openclaw/

pnpm install
```

## 2. 构建 UI
```bash
pnpm ui:build
```

## 3. 构建项目（生成 `dist/` 目录）
```bash
pnpm config set registry https://registry.npmmirror.com
pnpm build
```

## 4. 运行 onboarding 向导（引导配置网关、工作区、频道、技能等）
```bash
pnpm openclaw onboard --install-daemon
```

## 5. 开发循环（源码/配置变更时自动重载）
```bash
pnpm gateway:watch
```

## 6. 获取可用的 dashboard URL（推荐）
```bash
pnpm openclaw dashboard --no-open
```

## 常见问题：token 根本没配置/不工作怎么办？
先生成 gateway token：
```bash
pnpm openclaw doctor --generate-gateway-token
```

然后再执行一次：
```bash
pnpm openclaw dashboard --no-open
```
